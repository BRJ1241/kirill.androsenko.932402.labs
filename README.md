1. Три способа подключения стилей
В работе используются все три способа подключения CSS:
Внешний файл style.css — основное оформление (фон, шрифты, цвета, отступы, позиционирование).
Внутренний блок <style> в <head> — стили для списка навыков (выравнивание по центру через .skills).
Inline-стиль прямо в теге формы: style="display: flex; flex-direction: column;" — задаёт вертикальное расположение полей формы.

3. Позиционирование: static, relative, absolute
По заданию нужно было показать три вида позиционирования.
static — у <header>. Это значение по умолчанию: элемент стоит в обычном потоке, ничего особенного с ним не происходит. Оставлено явно, чтобы показать пример.
relative — у <main>. Элемент остаётся в потоке, но может сдвигаться относительно своего обычного места. Здесь это нужно ещё и как «точка отсчёта» для aside.
absolute — у <aside>. Боковой блок «вынимается» из потока и прикрепляется к правому верхнему углу <main> (потому что main имеет position: relative).
Важно: если бы у main не было relative, aside отсчитывался бы не от main, а от всего окна браузера. Именно поэтому main — relative, а aside — absolute: они работают в паре.
4. Псевдоклассы: :hover, :active, :focus, :visited
Псевдоклассы — это состояния элемента. Например, «наведён курсор», «нажат», «в фокусе», «уже посещён».
:hover - при наведении курсора на кнопку или ссылку .btn она слегка меняет цвет (opacity: 0.85). Пользователь видит, что элемент «живой».
:active - при нажатии кнопка «вдавливается» (transform: scale(0.95)) и меняет цвет. Это визуальная обратная связь.
:focus - при переходе клавишей Tab на кнопку, ссылку или переключатель темы появляется рамка outline. Это нужно, чтобы пользователь видел, где сейчас фокус.
:visited - у ссылки .btn цвет текста меняется на фиолетовый, если ссылка уже открывалась.
Изначально в коде было правило button:visited - но у кнопок нет состояния «посещено», это свойство только у ссылок. Также .btn:visited менял фон — а браузеры это запрещают из соображений приватности. Разрешено менять только цвет текста. Исправлено.
5. Переключение темы 
В шапке есть два переключателя:
<span class="theme-switch1" tabindex="0"> Немецкий</span>
<span class="theme-switch2" tabindex="0"> Русский</span>
При клике на «Немецкий» к <body> добавляется класс theme-de. 
Так одним щелчком меняется всё оформление: и цвета, и шрифт. Это и есть «переключение языка» через CSS-переменные.
Обратите внимание: классы theme-switch1 и theme-switch2 сами по себе ничего не знают о CSS-переменных - они только переключают класс theme-de. Вся логика смены темы - в CSS. Скрипт лишь добавляет и убирает класс на <body>.

Не было :focus, :hover, :visited для нужных элементов. button:visited вообще не работает (у кнопок нет такого состояния), а .btn:visited менял фон — браузеры это запрещают.
