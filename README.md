Что это такое
Это та же страница-визитка, что и в ЛР №2, но дополненная тремя новыми блоками и адаптивной вёрсткой. Теперь страница:

Что нового по сравнению с ЛР №2?
Если в ЛР №2 страница была просто набором блоков друг под другом, то в ЛР №3 добавлены:
1)Навигационное меню под шапкой — со ссылками на разделы «Навыки», «Проекты», «Обратная связь».
2)Секция «Изучаемые языки» — три карточки с флагами и уровнем владения.
3)Секция «Фраза недели» — три блока с пословицами на трёх языках, переводами и транскрипцией.
4)Адаптивность — медиа-запросы, которые перестраивают страницу под планшет и телефон.
5)Защита от горизонтальной прокрутки.

Что было сделано по заданию?
1. Flexbox — навигационное меню
Меню сделано на Flexbox — технологии, которая выстраивает элементы в ряд и управляет расстоянием между ними.
2. Flexbox — карточки «Изучаемые языки»
Три карточки (русский, английский, немецкий) лежат в ряд и переносятся на новую строку, если не помещаются.
3. Grid — галерея «Фраза недели»
Три блока «Фраза недели» лежат в CSS Grid — технологии для двумерных сеток (строки + колонки одновременно).
4. Содержимое блока «Фраза недели»
Каждый блок — это <article> с основной фразой на одном языке и переводами на два других.
5. Медиа-запросы — адаптивность
Медиа-запрос — это правило CSS, которое применяется только при определённой ширине экрана.
> 900px	Всё как есть: 3 карточки в ряд, 3 колонки в галерее, меню горизонтальное
600–900px	Галерея — 2 колонки
< 600px	Меню вертикальное, галерея в 1 колонку, main теряет padding-right
6. Защита от горизонтальной прокрутки
Горизонтальная прокрутка — это когда страница «шире» экрана, и появляется полоса внизу. Это плохо: пользователю приходится водить пальцем вбок, чтобы прочитать текст.
7. Контрастность текста ≥ 4.5:1
По стандарту WCAG текст должен иметь контраст с фоном не меньше 4.5:1 — иначе он плохо читается людьми со слабым зрением.

Как всё работает вместе 
Представим, что пользователь открыл страницу на телефоне и прокрутил до «Изучаемых языков».
Браузер прочитал медиа-запрос @media (max-width: 600px) — ширина экрана 375px меньше 600px, значит применяются мобильные правила.
.nav-menu → flex-direction: column — меню стало вертикальным.
.grid-gallery → grid-template-columns: 1fr — галерея в одну колонку.
.cards → карточки переносятся благодаря flex-wrap: wrap — по одной в строку.
Пользователь кликает «Немецкий» — JavaScript добавляет класс theme-de к <body>.
CSS видит этот класс и подменяет переменные: --primary с lightblue на #FF6633, --font0 на Georgia. Фон и шрифт меняются на всей странице одним махом.

Включить режим мобильного просмотра.
В выпадающем меню сверху выбрать устройства: iPhone, iPad, Galaxy.

Примечания
Форма не отправляет данные на сервер. action="#" — учебный приём, чтобы показать структуру формы без серверной обработки.
Аудио-иконка 🔊 — просто визуальный элемент, никаких звуков не воспроизводит.
Ссылка на GitHub ведёт на репозиторий с лабораторными работами.
Транскрипция указана в международном фонетическом алфавите (IPA) и дана у переводов, а не у исходных фраз — так удобнее понять, как читать именно перевод.
